# Морской бой

Консольное и графическое приложения для игры в морской бой. Правила, игровое состояние и интерфейсы репозиториев находятся в модуле `core`; пользовательские интерфейсы — в `cli` и `gui`.

## Сборка и запуск

Требуется JDK 17.

```bash
./gradlew build
./gradlew :cli:run
./gradlew :gui:run
```

## Консольные команды

- `add_player <name>` — добавить игрока и получить его ID.
- `start_game <id1> <id2>` — создать партию для двух игроков. Перед запуском проверяются обе случайные расстановки кораблей.
- `move <game_id> <player_id> <x> <y>` — записать выстрел. Координаты поля: от 0 до 9.
- `exit` — завершить приложение.

После запуска партии и каждого хода консоль показывает поле, очередь хода (или победителя после завершения) и журнал попыток. На своём поле `S` — неповреждённый сегмент корабля, `X` — попадание, `o` — промах, `.` — неизвестная клетка или вода. На поле противника корабли скрыты.

CLI и GUI используют SQLite-базу `~/.sea-battle/battleship.db`. В ней сохраняются игроки, рейтинги, партии, расстановки, состояние досок, очередь хода, журнал ходов и статистика игроков. Незавершённую партию можно восстановить после перезапуска приложения.

При запуске GUI отсутствующие в базе профили импортируются из существующего `~/.sea-battle/players.csv`; уже сохранённые в SQLite профили не перезаписываются. Исходный CSV не удаляется. Схема компонентов описана в [docs/architecture.md](docs/architecture.md).
