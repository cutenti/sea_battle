# Морской бой

Консольное приложение для записи ходов партии в морской бой и проверки их по правилам. Правила, игровое состояние и интерфейсы репозиториев находятся в модуле `core`; консольный ввод и отображение — в `cli`.

## Сборка и запуск

Требуется JDK 17.

```bash
./gradlew test
./gradlew :cli:run
```

## Консольные команды

- `add_player <name>` — добавить игрока и получить его ID.
- `start_game <id1> <id2>` — создать партию для двух игроков. Перед запуском проверяются обе случайные расстановки кораблей.
- `move <game_id> <player_id> <x> <y>` — записать выстрел. Координаты поля: от 0 до 9.
- `exit` — завершить приложение.

После запуска партии и каждого хода консоль показывает поле, очередь хода (или победителя после завершения) и журнал попыток. На своём поле `S` — неповреждённый сегмент корабля, `X` — попадание, `o` — промах, `.` — неизвестная клетка или вода. На поле противника корабли скрыты.

Данные репозиториев хранятся в памяти и сбрасываются при завершении приложения. Архитектура описана в [docs/architecture.md](docs/architecture.md).
